# Rom-mm Tap

## How do I install these formulae?

`brew install rom-mm/tap/<formula>`

Or `brew tap rom-mm/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rom-mm/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
